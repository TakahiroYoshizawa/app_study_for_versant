# Part B リピート練習

Versant の Part B（おうむ返し）だけを練習するアプリです。本番の試験ではありません。

## 起動

```bash
npm install
npm run dev
```

Chrome で開いてください。採点はブラウザの音声認識（Web Speech API）で行い、音声も文字もサーバには送りません。Safari と Firefox では認識できないことがあります。

## 採点と記録

聞こえた文の単語が順に揃っていれば正解です。抜けと言い換えがあると不正解で、その問題にチェックが付きます。3回連続で正解すると、その問題は理解できたものとします。

内容点は単語の一致率です。総合点は内容点に、合図から話し始めるまでの時間で係数をかけた練習用の目安です。発音は採点しません。
